FAQ

Questions, answered

Does it work with both MySQL and SQLite?

Yes. The platform runs on MySQL in production and automatically falls back to a local SQLite file when MySQL isn't reachable, so the demo works with zero setup. The schema and queries are identical across both.

How are blocked aisles and detours handled?

The warehouse is modelled as a graph of aisles, crossways and pick nodes. When an edge is marked blocked, shortest paths are recomputed over the remaining graph and the route is re-sequenced, so pickers get a valid detour instantly.

How fast is the TSP solver on large pick lists?

Typical waves of 20–40 picks resolve in about 0.4 seconds. We seed a nearest-neighbour tour and refine it with 2-Opt swaps, which gives near-optimal routes. Very small lists can be solved exactly.

Can it integrate with our existing WMS?

Yes. Orders, SKU velocity and locations can be imported via CSV or a REST API, and optimized pick lists and slotting recommendations are exported back in the same formats, so it can sit alongside your current WMS.

Who can see what? How does access control work?

Three roles — Operations Manager, Picker Lead and Fleet Coordinator — each see only the tools relevant to them, and every optimization run and configuration change is written to the audit trail.
